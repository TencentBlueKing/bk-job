# V3.12.7 Release Notes

These notes summarize the major new features, improvements, and bug fixes in the 3.12 series through V3.12.7.

## New Features

### Job Orchestration and Execution

- [New] Quick execution, job templates, and execution plan steps now support hosts or containers as execution targets. Containers can be selected by cluster, namespace, Workload, Pod, and container. Common workloads and CRDs, including GameStatefulSet and GameDeployment, are supported. Container execution is disabled by default; enable `job.features.containerExecution.enabled` before use. [Details](http://github.com/TencentBlueKing/bk-job/issues/3523)
- [New] Container targets support dynamic selection and condition-based filtering. [Details](http://github.com/TencentBlueKing/bk-job/issues/4336)
- [New] The "Host List" global variable has been upgraded to "Execution Target" and can contain both hosts and containers. Magic variables output hosts as "Cloud Area ID:Private IP" and containers as "Cluster/Namespace/Pod/Container"; `JOB_LAST_*` variables also output values according to the execution target type. [Details](http://github.com/TencentBlueKing/bk-job/issues/3524)
- [New] Added an execution account variable that can be referenced by script and file steps, allowing different execution plans to use different system accounts. [Details](http://github.com/TencentBlueKing/bk-job/issues/4364)
- [New] Added a built-in Windows Administrator execution account alongside the existing Linux root and Windows system accounts. [Details](http://github.com/TencentBlueKing/bk-job/issues/3444)
- [New] Execution plan variables can follow or not follow the job template. Variables that follow the template cannot be modified independently in the plan and are updated to the template's default values when the plan is synchronized. Variables that do not follow the template retain their own values. [Details](http://github.com/TencentBlueKing/bk-job/issues/3954)
- [New] File distribution supports rolling execution by source file. The rolling target can be set to "Transfer Targets" or "Source Files"; parallel staggered rolling execution is also supported. [Details](http://github.com/TencentBlueKing/bk-job/issues/4368)
- [New] Windows targets support custom script interpreters: for scripts other than Shell and SQL, specify the absolute path to an `.exe` file on the target machine. Linux hosts in the same target batch continue to use their system interpreters. [Details](http://github.com/TencentBlueKing/bk-job/issues/3321)
- [New] Execution results include Pod, container, and other container target properties to help identify execution targets.

### AI-Assistant and Agent Skills

- [New] AI-Assistant supports script checks, error analysis for failed tasks, and general questions. A model service must be configured by the platform before use. AI suggestions do not replace dangerous statement scanning and blocking.
- [New] AI-related components can be initialized automatically to simplify deployment configuration. [Details](http://github.com/TencentBlueKing/bk-job/issues/4484)
- [New] Added Agent Skills for regular users to query resources, execution history, and logs; quickly execute scripts; distribute server or local files; and create execution plans and scheduled tasks. Multi-tenant configuration is supported. [Details](http://github.com/TencentBlueKing/bk-job/issues/4158)

### File Sources and Distribution

- [New] File source and credential features are enabled by default in containerized deployments.
- [New] File distribution supports files from file sources in addition to local and server files.
- [New] Machines outside the cluster with an Agent installed can serve as local distribution sources. [Details](http://github.com/TencentBlueKing/bk-job/issues/3467)

### Scheduled Tasks, Selectors, and Permissions

- [New] Scheduled tasks support IANA time zones, such as `Asia/Shanghai`, and use the business time zone by default. [Details](http://github.com/TencentBlueKing/bk-job/issues/3924)
- [New] Scheduled tasks support task-level notifications, with the option to inherit business settings or customize recipients and notification methods. [Details](http://github.com/TencentBlueKing/bk-job/issues/3557)
- [New] Message notifications support WeCom. [Details](http://github.com/TencentBlueKing/bk-job/issues/4244)
- [New] Scheduled task details provide a shareable link that opens the corresponding task with its details expanded. [Details](http://github.com/TencentBlueKing/bk-job/issues/3907)
- [New] The IP selector supports batch input of Host IDs and copying Host IDs or Cloud Area:IP values. Container targets support copying container IDs. [Details](http://github.com/TencentBlueKing/bk-job/issues/4123)
- [New] Node lists in the target server's static topology display the cluster and module to which each node belongs. [Details](http://github.com/TencentBlueKing/bk-job/issues/3973)
- [New] Selecting all nodes in a business now requires confirmation to avoid unintentionally selecting an overly broad execution scope. [Details](http://github.com/TencentBlueKing/bk-job/issues/3687)
- [New] Execution operations, including script execution, file distribution, and job startup, support permission applications based on CMDB topology nodes. Static IP and Host ID targets continue to use host-based authorization. [Details](http://github.com/TencentBlueKing/bk-job/issues/3213)
- [New] Added IAM V4 integration. [Details](http://github.com/TencentBlueKing/bk-job/issues/4513)

### Resource Scopes and Deployment

- [New] The business list distinguishes between businesses, business sets, and tenant sets. [Details](http://github.com/TencentBlueKing/bk-job/issues/3686)
- [New] The operations view displays execution failure counts and failure rates.
- [New] Added multi-tenancy support. By default, the platform continues to run in single-tenant mode with the `default` tenant. [Details](http://github.com/TencentBlueKing/bk-job/issues/3369)
- [New] Supports multi-namespace and multi-cluster deployments, as well as deployment under a subpath of the BlueKing domain. [Details](http://github.com/TencentBlueKing/bk-job/issues/3917)
- [New] Added KMS integration. [Details](http://github.com/TencentBlueKing/bk-job/issues/4543)

### OpenAPI

- [New] Added v4 APIs for script execution and result queries while retaining compatibility with v3 APIs. The v4 APIs cover resource scopes, container execution targets, quick file distribution, execution plans, scheduled task time zones, and log queries by execution target. [Details](http://github.com/TencentBlueKing/bk-job/issues/3845)
- [New] Added OpenAPI v4 endpoints and documentation for creating and updating job templates, and updating and synchronizing execution plans. [Details](http://github.com/TencentBlueKing/bk-job/issues/4453)
- [New] Added OpenAPI v4 endpoints for creating execution plans and retrieving job template details. [Details](http://github.com/TencentBlueKing/bk-job/issues/4247)
- [New] Added OpenAPI v4 endpoints for querying a user's authorized resource scopes and execution targets within a business. [Details](http://github.com/TencentBlueKing/bk-job/issues/4422)
- [New] Added approval-based APIs for script execution, file distribution, starting execution plans, and other operations. [Details](http://github.com/TencentBlueKing/bk-job/issues/4441)
- [New] Added an API Gateway endpoint for distributing files to containers. [Details](http://github.com/TencentBlueKing/bk-job/issues/3542)
- [New] The quick script execution API accepts passwords for Windows targets. [Details](http://github.com/TencentBlueKing/bk-job/issues/3636)
- [New] Added an OpenAPI endpoint for querying business-level message notification settings and an API for updating user information in account management. [Details](http://github.com/TencentBlueKing/bk-job/issues/2938)

## Improvements

### User Experience

- [Improved] Upgraded the script editor to Monaco with search support. [Details](http://github.com/TencentBlueKing/bk-job/issues/4085)
- [Improved] Successfully completed tasks no longer display the AI-Assistant entry point. Improved responses in cases such as missing logs.
- [Improved] Task timeouts can be set from 1 to 259200 seconds, defaulting to 7200 seconds when left blank. A lower maximum can be configured per business. The reduced default timeout prevents abnormal tasks from occupying the execution engine for extended periods.
- [Improved] Message notifications support per-business quotas, with improved handling of invalid notification users. [Details](http://github.com/TencentBlueKing/bk-job/issues/3328)
- [Improved] Times displayed on pages support personal time zones.
- [Improved] Script parameter limits are based on data size rather than character count.
- [Improved] Added fuzzy-search hints for static topology searches in the IP selector and improved performance when selecting large numbers of containers. [Details](http://github.com/TencentBlueKing/bk-job/issues/4141)
- [Improved] Selecting any single container for execution now uses random scheduling to avoid repeatedly scheduling retries to the same node. [Details](http://github.com/TencentBlueKing/bk-job/issues/3352)
- [Improved] Scheduled task lists fetch basic information on demand for faster loading and more accurate display of the latest execution results. Updated caching for "Use Last Execution Parameters" to prevent page errors caused by oversized parameters. [Details](http://github.com/TencentBlueKing/bk-job/issues/4510)
- [Improved] Optimized data retrieval in the business selector to reduce page lag, and improved host copying in the homepage Agent status list. [Details](http://github.com/TencentBlueKing/bk-job/issues/4124)
- [Improved] The read status of release notes no longer relies solely on browser cookies. Updated the release notes URL. [Details](http://github.com/TencentBlueKing/bk-job/issues/4022)
- [Improved] Improved messages for file source authentication failures, cross-business sharing, and file preparation failures to simplify troubleshooting. [Details](http://github.com/TencentBlueKing/bk-job/issues/4504)
- [Improved] After applying for execution account permissions, the destination page displays the account's topology information. [Details](http://github.com/TencentBlueKing/bk-job/issues/2428)

### APIs and Error Messages

- [Improved] Quick execution APIs prevent duplicate calls and validate hosts. Fuzzy task history queries and task list APIs include scope and parameter validation.
- [Improved] Improved error messages for log queries with nonexistent IPs, job startup with invalid host data or execution targets, overly long script parameters, and distribution of nonexistent files to help users troubleshoot independently.
- [Improved] Strengthened validation for job templates, file sources, public scripts, scheduled task names, and other parameters. [Details](http://github.com/TencentBlueKing/bk-job/issues/4573)
- [Improved] Clarified API response field descriptions, selected request and response parameter definitions, and the API Gateway documentation hierarchy. [Details](http://github.com/TencentBlueKing/bk-job/issues/4353)
- [Improved] Task logs for deleted hosts can be queried through APIs. [Details](http://github.com/TencentBlueKing/bk-job/issues/4100)
- [Improved] The `get_job_plan_detail` API returns step enabled status. [Details](http://github.com/TencentBlueKing/bk-job/issues/4420)
- [Improved] Lightweight mode supports OpenAPI v4 endpoints. [Details](http://github.com/TencentBlueKing/bk-job/issues/4379)
- [Improved] Added clearer messages when sensitive parameters exceed storage length limits. [Details](http://github.com/TencentBlueKing/bk-job/issues/3546)

### Deployment and Runtime

- [Improved] Upgraded the backend runtime to JDK 17 and updated Spring Boot and related dependencies. [Details](http://github.com/TencentBlueKing/bk-job/issues/3836)
- [Improved] Health checks validate MongoDB passwords. Component SSL support covers MySQL 8.0, and Ingress supports Tencent Cloud CLB.
- [Improved] Modules support additional volume injection for custom mounts. Refined Role permissions required for containerized deployments. [Details](http://github.com/TencentBlueKing/bk-job/issues/2738)
- [Improved] Optimized file source health checks, total job execution time, long-running inter-service calls, and task startup time for large host batches. [Details](http://github.com/TencentBlueKing/bk-job/issues/4371)
- [Improved] Improved import and export of accounts referenced by job templates, as well as target host matching after import.
- [Improved] Improved scheduled task compatibility with invalid hosts and optimized loading strategies. Services support graceful shutdown and controlled transitions into and out of service. [Details](http://github.com/TencentBlueKing/bk-job/issues/4162)
- [Improved] Optimized File-Worker online state transitions, execution record archiving, and data storage. [Details](http://github.com/TencentBlueKing/bk-job/issues/4552)
- [Improved] Multi-tenant mode supports automatic initialization of system tenants. [Details](http://github.com/TencentBlueKing/bk-job/issues/4452)
- [Improved] Added source validation for callback URLs. [Details](http://github.com/TencentBlueKing/bk-job/issues/4099)
- [Improved] Added the official migration tool for upgrades from 3.11.x to 3.12.x. Validate the SQL in a canary environment before upgrading. [Details](http://github.com/TencentBlueKing/bk-job/issues/4037)
