# V3.12.7 版本更新日志

本日志汇总 3.12 系列截至 V3.12.7 的主要新增功能、优化和修复。

## 新增

### 编排与执行

- [新增] 快速执行、作业模板和执行方案的步骤目标均支持主机或容器，可按「集群 - 命名空间 - Workload - Pod - 容器」选择。支持常见工作负载和 CRD，包括 GameStatefulSet、GameDeployment。容器执行默认关闭，使用前需开启 `job.features.containerExecution.enabled`。[详情](http://github.com/TencentBlueKing/bk-job/issues/3523)
- [新增] 容器目标支持动态选择和条件筛选。[详情](http://github.com/TencentBlueKing/bk-job/issues/4336)
- [新增] 全局变量「主机列表」升级为「执行目标」，可同时包含主机和容器。魔法变量中，主机以「云区域ID:内网IP」输出，容器以「集群/命名空间/Pod/容器」输出；`JOB_LAST_*` 同样按执行对象输出。[详情](http://github.com/TencentBlueKing/bk-job/issues/3524)
- [新增] 支持「执行账号」变量，脚本步骤和文件步骤均可引用，不同执行方案可使用不同的系统账号。[详情](http://github.com/TencentBlueKing/bk-job/issues/4364)
- [新增] 内置 Windows Administrator 执行账号，保留原有 Linux root、Windows system 账号。[详情](http://github.com/TencentBlueKing/bk-job/issues/3444)
- [新增] 执行方案变量可设置「跟随作业」或「不跟随作业」。跟随作业时，方案中的变量值不可单独修改，同步执行方案时更新为作业模板的默认值；不跟随作业时，方案保留自己的变量值。[详情](http://github.com/TencentBlueKing/bk-job/issues/3954)
- [新增] 文件分发支持按源文件滚动执行，滚动对象可选择「传输目标」或「源文件」；文件分发滚动执行支持并行错峰模式。[详情](http://github.com/TencentBlueKing/bk-job/issues/4368)
- [新增] Windows 目标支持自定义脚本解释器：非 Shell、非 SQL 脚本可填写目标机上 `.exe` 文件的绝对路径。同一批目标中的 Linux 主机仍使用系统解释器。[详情](http://github.com/TencentBlueKing/bk-job/issues/3321)
- [新增] 执行结果补充容器目标的 Pod、容器等属性，便于定位执行对象。

### AI 小鲸与 Agent Skills

- [新增] AI 小鲸支持脚本检查、失败任务报错分析和一般提问。使用前需由平台配置模型服务，AI 建议不能替代高危语句扫描与拦截。
- [新增] 支持自动初始化 AI 相关组件，简化部署配置。[详情](http://github.com/TencentBlueKing/bk-job/issues/4484)
- [新增] 提供面向普通用户的 Agent Skills，支持查询资源、执行历史与日志，快速执行脚本、分发服务器文件或本地文件，以及创建执行方案和定时任务；支持多租户配置。[详情](http://github.com/TencentBlueKing/bk-job/issues/4158)

### 文件源与分发

- [新增] 容器化部署默认开启文件源和凭证功能；二进制部署需开启 `job.features.fileManage`。
- [新增] 文件分发除本地文件、服务器文件外，还可选择文件源文件。
- [新增] 集群外已安装 Agent 的机器可作为本地分发源。[详情](http://github.com/TencentBlueKing/bk-job/issues/3467)

### 定时任务、选择器与权限

- [新增] 定时任务支持 IANA 时区，如 `Asia/Shanghai`，默认使用业务时区。[详情](http://github.com/TencentBlueKing/bk-job/issues/3924)
- [新增] 定时任务支持任务级通知，可选择继承业务设置或自定义通知对象与方式。[详情](http://github.com/TencentBlueKing/bk-job/issues/3557)
- [新增] 消息通知支持企业微信。[详情](http://github.com/TencentBlueKing/bk-job/issues/4244)
- [新增] 定时任务详情支持复制分享链接，打开链接后可定位到对应任务并展开详情。[详情](http://github.com/TencentBlueKing/bk-job/issues/3907)
- [新增] IP 选择器支持批量输入 Host ID，并支持复制 Host ID、云区域:IP；容器目标支持复制容器 ID。[详情](http://github.com/TencentBlueKing/bk-job/issues/4123)
- [新增] 目标服务器静态拓扑中的节点列表支持展示节点所属的集群和模块。[详情](http://github.com/TencentBlueKing/bk-job/issues/3973)
- [新增] 选中业务下全部节点时增加确认，避免误选过大执行范围。[详情](http://github.com/TencentBlueKing/bk-job/issues/3687)
- [新增] 脚本执行、文件分发、启动作业等执行类操作支持按 CMDB 拓扑节点申请权限；静态 IP、Host ID 仍按主机授权。[详情](http://github.com/TencentBlueKing/bk-job/issues/3213)
- [新增] 对接 IAM V4。[详情](http://github.com/TencentBlueKing/bk-job/issues/4513)

### 资源范围与部署

- [新增] 业务列表区分业务、业务集和租户集。[详情](http://github.com/TencentBlueKing/bk-job/issues/3686)
- [新增] 运营视图增加执行失败次数、失败率。
- [新增] 支持多租户，默认仍按单租户 `default` 运行。[详情](http://github.com/TencentBlueKing/bk-job/issues/3369)
- [新增] 支持多命名空间、多集群部署，以及蓝鲸域名加子路径部署。[详情](http://github.com/TencentBlueKing/bk-job/issues/3917)
- [新增] 支持对接 KMS。[详情](http://github.com/TencentBlueKing/bk-job/issues/4543)

### OpenAPI

- [新增] 执行脚本、查询结果提供 v4 接口，v3 接口保持兼容。v4 接口支持资源范围、容器执行对象、快速分发文件、执行方案、定时任务时区及按执行对象查询日志等能力。[详情](http://github.com/TencentBlueKing/bk-job/issues/3845)
- [新增] 提供创建、更新作业模板，以及更新、同步执行方案的 OpenAPI v4 接口及对应文档。[详情](http://github.com/TencentBlueKing/bk-job/issues/4453)
- [新增] 提供创建执行方案、获取作业模板详情的 OpenAPI v4 接口。[详情](http://github.com/TencentBlueKing/bk-job/issues/4247)
- [新增] 提供查询用户有权限资源范围、查询业务下执行目标的 OpenAPI v4 接口。[详情](http://github.com/TencentBlueKing/bk-job/issues/4422)
- [新增] 提供带审批流程的脚本执行、文件分发、启动执行方案等接口。[详情](http://github.com/TencentBlueKing/bk-job/issues/4441)
- [新增] 提供容器作为文件分发执行对象的 API 网关接口。[详情](http://github.com/TencentBlueKing/bk-job/issues/3542)
- [新增] 快速执行脚本接口支持为 Windows 目标传入密码。[详情](http://github.com/TencentBlueKing/bk-job/issues/3636)
- [新增] 提供查询业务级消息通知配置的 OpenAPI，以及修改账号管理中用户信息的 API。[详情](http://github.com/TencentBlueKing/bk-job/issues/2938)
- [新增] 提供获取公共应用个人凭证的接口。[详情](http://github.com/TencentBlueKing/bk-job/issues/4362)

## 优化

### 使用体验

- [优化] 脚本编辑器升级为 Monaco，支持搜索。[详情](http://github.com/TencentBlueKing/bk-job/issues/4085)
- [优化] 执行成功的任务不再显示 AI 小鲸入口，优化无日志等特殊场景下的回复。
- [优化] 任务超时允许设置为 1～259200 秒，留空默认 7200 秒，并可按业务设置更小的上限。下调默认超时，避免异常任务长期占用执行引擎。
- [优化] 消息通知支持按业务配额控制，并优化无效通知用户的处理。[详情](http://github.com/TencentBlueKing/bk-job/issues/3328)
- [优化] 页面时间展示支持个人时区。
- [优化] 脚本参数限制由字符长度改为字符大小。
- [优化] IP 选择器静态拓扑搜索增加模糊搜索提示，优化大批量容器选择性能。[详情](http://github.com/TencentBlueKing/bk-job/issues/4141)
- [优化] 任意选择一个容器执行时改为随机调度，避免重试总落到同一节点。[详情](http://github.com/TencentBlueKing/bk-job/issues/3352)
- [优化] 定时任务列表按需拉取基础信息，优化加载速度和最新执行结果展示；「填入上一次执行参数」调整缓存方式，避免参数过大导致页面异常。[详情](http://github.com/TencentBlueKing/bk-job/issues/4510)
- [优化] 业务选择器优化数据拉取，减轻页面卡顿；优化首页 Agent 状态列表中的主机复制操作。[详情](http://github.com/TencentBlueKing/bk-job/issues/4124)
- [优化] 版本日志已读状态不再只依赖浏览器 Cookie，并更新版本日志访问地址。[详情](http://github.com/TencentBlueKing/bk-job/issues/4022)
- [优化] 文件源认证失败、跨业务共享及文件准备失败时的提示，便于定位问题。[详情](http://github.com/TencentBlueKing/bk-job/issues/4504)
- [优化] 申请执行账号权限后，跳转页面可展示账号的拓扑信息。[详情](http://github.com/TencentBlueKing/bk-job/issues/2428)
