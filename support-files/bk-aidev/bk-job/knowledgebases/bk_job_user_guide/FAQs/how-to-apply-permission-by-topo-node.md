# 执行类操作如何按拓扑节点申请权限？

3.11 起，脚本执行、文件分发、启动作业等执行类操作支持按配置平台的**业务拓扑节点**申请权限并鉴权，不必再按整业务或逐台主机申请。

## 使用方式

1. 在 IP 选择器中通过「拓扑选择节点」勾选集群、模块等节点
2. 当前账号若缺少这些节点的执行权限，提交时会弹出权限申请，申请范围就是所选节点（及其下主机）
3. 审批通过后，对该节点下的主机执行脚本或分发文件即可通过鉴权

按 IP / Host ID 勾选的静态主机，仍按主机维度鉴权；动态分组保持原有鉴权方式。

## 注意

- 业务集、租户集范围下不支持动态分组和容器，拓扑权限申请以该范围内实际可选的主机拓扑为准
- 权限策略由权限中心管理，作业平台只消费已授权的拓扑范围
- 选中业务下全部节点时，页面会弹出警告确认，避免误对全业务主机下发任务
