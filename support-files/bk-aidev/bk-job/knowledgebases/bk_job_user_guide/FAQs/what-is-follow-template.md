# 执行方案变量「跟随作业」是什么意思？

3.12 起，执行方案里的每个全局变量都可以单独设置为「跟随作业」或「不跟随作业」。

## 跟随作业

- 方案侧该变量的值被锁定，不能在方案中直接修改
- 作业修改变量默认值后，方案会使用作业的最新值
- 批量编辑方案变量时，跟随作业的变量会被跳过

适合「所有方案都应与作业保持同一默认值」的变量，例如统一的超时提示文案、统一的执行账号。

## 不跟随作业

- 方案可以保留并修改自己的变量值
- 作业只改默认值或描述时，本来就不会造成方案不同步；不跟随作业的方案值也不会被作业覆盖

适合「同一作业、不同方案填不同目标 / 不同账号」的变量。

## 和同步状态的关系

「跟随作业」管的是**方案变量值是否跟随作业中的默认值**，与方案是否出现「待同步」不是同一件事。

作业增删变量、改变量名 / 类型 / 必填等，仍会让方案进入待同步。同步时：

- 跟随作业的变量按作业重建
- 不跟随作业的变量会尽量保留方案自己的值
