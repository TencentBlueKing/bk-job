# 如何使用执行账号变量？

当同一套作业要在不同环境、不同主机身份下执行时，如果把执行账号写死在步骤里，每换一批机器就要改模板再同步方案。3.12 起可以把执行账号抽成全局变量。

## 适用场景

- 同一模板在测试 / 预发 / 生产使用不同系统账号
- 文件分发的源账号和目标账号需要按方案切换
- 希望执行时再确认账号，而不是改步骤内容

## 操作步骤

1. 在作业模板的「全局变量」中新增类型为 `执行账号` 的变量，例如 `exec_account`
2. 设置初始值（可选）和是否「执行时必填」
3. 在脚本步骤或文件步骤的「执行账号」中，选择「账号变量」，并指定 `exec_account`；文件源主机账号同样可以引用账号变量
4. 生成执行方案后，在方案中为该变量填入本场景要使用的账号
5. 若希望方案始终使用作业里的默认账号，把该变量设为「跟随作业」；否则保持不跟随作业，由方案各自维护

## 注意

- 执行账号变量不能跨步骤改写（不属于「赋值可变」类型）
- 业务下必须已存在对应的系统账号，变量只是引用，不会自动创建账号
- 内置账号包括 Linux `root`、Windows `system` 和 `Administrator`，也可引用用户自建账号
